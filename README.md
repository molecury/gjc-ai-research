# Human CD73 (NT5E) drug landscape

Accessed: **2026-09-17** (Asia/Seoul)

## Scope

This report covers therapeutic agents that directly target human CD73/ecto-5'-nucleotidase (`NT5E`), including antibodies, engineered biologics, small molecules, antibody-drug conjugates, and cell therapies. The canonical target is human wild-type CD73: UniProt **P21589**, Ensembl **ENSG00000135318**, and ChEMBL target **CHEMBL5957**.

Diagnostic radiotracers, treatments for NT5E-deficiency phenotypes that do not bind CD73, background combination drugs, and studies that only measure CD73 as a biomarker were excluded from the therapeutic table.

No approved CD73-directed therapy was identified in the queried sources. No candidate was annotated as binding a specific CD73 sequence variant; clinical programs target wild-type protein or select patients by CD73 expression.

## Variant interpretation

- The canonical reviewed human protein record is UniProt P21589 (`NT5E`, CD73), with Ensembl gene ENSG00000135318.
- None of the retrieved therapeutic records specified a required amino-acid variant or mutant-selective binding mechanism.
- Several oncology trials select or stratify by **CD73 expression**. Expression selection is a biomarker strategy, not a sequence-variant-specific therapy.
- NT5E loss-of-function causes arterial calcification due to deficiency of CD73 (ACDC). The etidronate study [NCT01585402](https://clinicaltrials.gov/study/NCT01585402) treats the disease phenotype and is not a CD73-binding drug, so it is excluded above.

## Coverage and count reconciliation

- **UniProt:** 1 reviewed human `NT5E` record retrieved (P21589).
- **Open Targets:** current `drugAndClinicalCandidates` query returned 1 target-linked candidate, oleclumab, with 29 clinical/curated reports. This field substantially under-covered the broader registry landscape and was not treated as exhaustive.
- **ChEMBL target search:** 3 target search hits; the exact human single-protein target was CHEMBL5957/P21589.
- **ChEMBL mechanisms:** 1/1 mechanism record retrieved, oleclumab (CHEMBL3990016), with no pagination remainder.
- **ChEMBL activities:** expected 4,851; retrieved 4,851 in 5 pages; 1,305 unique molecule IDs; 25 had preferred names. These are bioactivity observations, not 1,305 validated drugs. The clinically recognizable named small molecules included quemliclustat and LY3475070.
- **ClinicalTrials.gov:** expected 137 records for `query.term=CD73`; retrieved 137 in one page; no next-page token. Records were locally filtered to direct therapeutic targeting. Biomarker-only, diagnostic, background-combination, and phenotype-treatment records were excluded.

## Reproducible endpoints and parameters

- UniProt: `GET https://rest.uniprot.org/uniprotkb/search`; query `(gene_exact:NT5E) AND (organism_id:9606) AND (reviewed:true)`.
- Open Targets GraphQL: `POST https://api.platform.opentargets.org/api/v4/graphql`; target `ENSG00000135318`; field `drugAndClinicalCandidates`.
- ChEMBL: `GET https://www.ebi.ac.uk/chembl/api/data/target/search.json?q=CD73+NT5E`; `GET /mechanism.json?target_chembl_id=CHEMBL5957`; `GET /activity.json?target_chembl_id=CHEMBL5957&limit=1000&offset={0,1000,2000,3000,4000}`.
- ClinicalTrials.gov v2: `GET https://clinicaltrials.gov/api/v2/studies?query.term=CD73&pageSize=1000&countTotal=true`; API version 2.0.5, data timestamp `2026-09-16T09:00:06`.

## Limitations

ClinicalTrials.gov is sponsor-submitted and aliases are inconsistently normalized. A `CD73` full-text query includes false positives and can miss a candidate when its record never names the target. ChEMBL contains extensive preclinical assay data but does not classify every tested molecule as a drug. Consequently, the table is an exhaustive retrieval of the bounded public queries above, followed by explicit local filtering; it is not a guarantee that every confidential, preclinical, discontinued, or regionally registered program is represented.
