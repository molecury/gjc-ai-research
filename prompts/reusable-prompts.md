# Reusable Research Prompts

특정 세션의 원본 대화가 아니라 여러 연구에서 재사용 가능한 프롬프트를 기록합니다.

## 연구 질문 정교화

```text
다음 연구 질문을 검증 가능한 하위 질문으로 분해하라.
각 하위 질문에 필요한 근거 유형, 반대 가설, 주요 불확실성을 함께 제시하라.
확인된 사실과 추론을 명확히 구분하라.
```

## 근거 비교

```text
다음 자료들을 주장별로 비교하라.
각 주장에 대해 지지 근거, 반대 근거, 연구 설계의 한계, 적용 가능 범위,
추가로 확인해야 할 원문을 구분하라. 인용을 추측하거나 만들지 말라.
```

## Deep Research 결과 감사

```text
이 연구 결과에서 원문 검증이 필요한 주장, 단일 출처에 의존한 주장,
인과관계로 과도하게 해석한 부분, 최신성 위험, 누락된 반대 근거를 찾아라.
각 항목의 검증 방법을 제안하라.
```

## 세션 종료 요약

```text
이번 연구 세션을 질문, 검색 전략, 핵심 근거, 상충하는 근거,
결정, 한계, 다음 단계 순서로 요약하라.
AI가 수행한 작업과 연구자가 직접 검증해야 할 작업을 분리하라.
```
